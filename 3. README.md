# Biologically Informed Digital Twin (BIDT) for Oral Tirzepatide Bilayer Matrix Tablets

This repository contains the core computational scripts and optimization data matrices for the research paper:
**"Development of a Biologically Informed Digital Twin for Predicting the Release Kinetics of Oral Tirzepatide Bilayer Matrix Tablets: An API-Sparing In-Silico Framework"**

## Repository Structure

- `01_rdkit_molecular_descriptors.py`: RDKit informatics script for computing physicochemical descriptors and ECFP4 fingerprint similarity.
- `02_rsm_ccd_optimization.py`: Response Surface Methodology (RSM) 13-run Central Composite Design (CCD) formulation optimization script.

## System Requirements
- Python 3.10+
- RDKit (`pip install rdkit`)
- NumPy, Pandas, SciPy
